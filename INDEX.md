## 🔧 CUSTOMIZATION (5 minutes)

### Change Backend Port
In `frontend-complete.html`, find:
```javascript
const API_BASE = 'http://localhost:3000';
```
Change `3000` to your port.

### Add More Avatars
Find `PLAYER_ICONS` array and add emojis:
```javascript
const PLAYER_ICONS = ['🤖', '🦁', '🐯', '🦊', '🐻', '🐼', '🐨', '🐸', '🐢'];
```

### Change Colors
Main color is `#667eea`. Search and replace.

## 🛠️ IF YOU HAVE ISSUES

1. **Backend won't start?** → `npm start` in root folder
2. **Can't connect to server?** → Check port 3000 is correct
3. **Players not syncing?** → Refresh page, check console (F12)
4. **Dice doesn't work?** → Make sure it's your turn
5. **Can't create room?** → Verify backend API is working
