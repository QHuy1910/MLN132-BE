  Display:
    • All available game rooms
    • Room details (host, players, spectators)
    • Join buttons
  
  Actions:
    • Enter player name
    • Choose character avatar (8 options)
    • Select role (Player / Spectator)
    • Create new room
    • Join existing room
  
  Updates: Real-time every 3 seconds

PAGE 2: ROOM LOBBY 👥
  Display:
    • List of all connected players
    • List of all spectators
    • Player status (online/offline)
    • Player money ($1500 each)
    • Room info (host, status, board size)
  
  Actions (Host only):
    • Start game (requires 2+ players)
  
  Actions (All):
    • Leave room
  
  Updates: Real-time via Socket.IO

PAGE 3: GAME BOARD 🎲
  Display:
    • 20-tile monopoly board
    • Player positions on board
    • Player stats panel
    • Dice value
    • Current turn indicator
  
  Actions (Current Player):
    • Roll Dice (1-6 random)
    • End Turn
  
  Actions (Other Players):
    • Watch and wait
  
  Updates: Real-time after each action
