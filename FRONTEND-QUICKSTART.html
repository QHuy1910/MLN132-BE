🎮 How to Play

Setup (First Time):

1 Enter your player name (max 20 characters)
2 Click your favorite avatar from 8 options (🤖 🦁 🐯 🦊 🐻 🐼 🐨 🐸)
3 Choose role: Player (to play) or Spectator (to watch)
4 Create new room or join existing room

Game (In Lobby):

1 Wait for host to gather players (need at least 2)
2 Host clicks "Start Game" when ready

Playing (On Board):

1 Watch the "Current Turn" indicator - it shows whose turn it is
2 When it's your turn, click "Roll Dice" button
3 Your token moves automatically by the dice value
4 Click "End Turn" to pass to next player
5 Repeat until game ends

🛠️ Troubleshooting

Issue: "Cannot connect to server"

Solution:
  • Make sure backend is running: npm start in project root
  • Backend should be on http://localhost:3000
  • Check firewall isn't blocking localhost
  • Try opening http://localhost:3000/api-docs to verify backend

Issue: Players not showing up in real-time

Solution:
  • Open browser console (F12) and check for errors
  • Verify backend is running
  • Check that Socket.IO is working in Network tab
  • Refresh the page and try again

Issue: Can't roll dice

Solution:
  • Check "Current Turn" - button only works on your turn
  • You can only roll once per turn
  • Click "End Turn" to enable rolling again

Issue: Backend on different port

Solution:
  • Open frontend-complete.html with a text editor
  • Find: const API_BASE = 'http://localhost:3000';
  • Change 3000 to your port number
  • Save and reload in browser

⚙️ Technical Details

Technologies Used:

  • React 18 - UI framework
  • Socket.IO - Real-time communication
  • Axios - HTTP client
  • React Router v6 - Page navigation

API Endpoints:

GET /api/rooms (Get all rooms) POST /api/rooms (Create room) GET /api/rooms/:id (Get room details) POST /api/rooms/:id/join (Join as player) POST /api/rooms/:id/spectators (Join as spectator) POST /api/rooms/:id/start (Start game) POST /api/rooms/:id/rollDice (Roll dice) POST /api/rooms/:id/endTurn (End turn)

Socket Events:

Client → Server: joinRoom, joinAsSpectator, startGame, rollDice, endTurn, leaveRoom Server → Client: gameStarted, diceRolled, playerMoved, turnEnded, playerJoined, spectatorJoined

❓ FAQ

Q: Do I need to install anything to use the frontend?

A: No! The standalone frontend-complete.html works in any browser. Just need the backend running.

Q: Can I use this on mobile?

A: Yes! The frontend is fully responsive and works on phones and tablets.

Q: Can spectators become players?

A: No, they must create a new room or join as a player. Their role is set when they join.

Q: What if someone disconnects?

A: The backend removes them from the room and broadcasts the change. Game continues with remaining players.

Q: How do I play with friends remotely?

A: Change API_BASE in the HTML to your server's IP address instead of localhost.

Q: Can I customize the game?

A: Yes! Edit frontend-complete.html to add more avatars, change colors, or modify board size.
